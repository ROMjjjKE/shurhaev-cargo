# shurhaev-cargo

Сайт грузоперевозок ИП Шурхаев В. А. (Беларусь): рефрижератор, мебель, передачи, попутные рейсы в Минск.

Стек: React + Vite + TypeScript, GSAP + ScrollTrigger (пин «холодная цепь»), Lenis.
Статика, GitHub Pages, деплой через Actions.

Структура: Hero, Cargo (4 направления), Cold (пин-сцена), Docs, Dirs, Steps, Faq, Ask, Footer.
Шрифты: Exo 2 600 + PT Sans 400/700, подрезаны по используемым символам, метрические фолбэки 97,02% и 92,62%.

Ограничения: город заказчик не указал — на сайте «город, область и РБ»; тарифов, тоннажа и графика
рейсов нет, всё подтверждается звонком. Цены и сроки не выдуманы.
